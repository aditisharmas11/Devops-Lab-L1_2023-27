# Project 2 - Deploy Angular Application in Docker Container

## Objective

The objective of this project is to deploy an Angular application inside a Docker container using Docker and Docker Compose.

---

## Tools & Technologies Used

- Angular CLI 18
- Node.js 20
- Docker Desktop
- Docker Compose
- Visual Studio Code

---

## Project Workflow

1. Installed Angular CLI.
2. Created a new Angular application.
3. Ran the Angular application locally.
4. Created a Dockerfile.
5. Created a docker-compose.yml file.
6. Built the Docker image.
7. Ran the Docker container.
8. Verified the deployed application in the browser.
