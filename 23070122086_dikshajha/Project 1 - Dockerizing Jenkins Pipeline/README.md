# Project 1 - Dockerizing Jenkins Pipeline

## Objective

The objective of this project is to implement a Continuous Integration (CI) pipeline using Jenkins to automate the process of building a Docker image for a Flask application.

## Project Workflow

1. Created a Flask application.
2. Dockerized the application using a Dockerfile.
3. Created a Jenkins Declarative Pipeline.
4. Connected Jenkins with the GitHub repository.
5. Built the Docker image automatically through Jenkins.
6. Verified the build using Jenkins Console Output.
